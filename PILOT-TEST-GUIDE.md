# Pilot Test Guide — Computer Foundations

## Recommended cohort
5–10 volunteer learners with varied technical backgrounds. Provide the site locally before publication or publish only after explicit approval.

## Pilot session (60–90 minutes)
1. **5 min:** Navigate the homepage. Ask learners to find the Computer Foundations path unaided.
2. **15 min:** Complete the binary/encoding simulation and explain one 8-bit value.
3. **15 min:** Run the network simulator, identify a failed connection and explain guest isolation.
4. **10 min:** Make a software-selection decision and explain the security implications.
5. **10 min:** Work through the service-desk ticket simulation and download a fictional record.
6. **15–30 min:** Answer at least one eight-question module quiz and download the progress summary.

## Success criteria
- At least 80% of pilot participants can reach a learning module without assistance.
- At least 80% can finish one simulation without instructor intervention.
- Learners can explain one real-world application of each completed concept.
- Quiz scores and perceived difficulty identify areas for revision; 80% is a practice target, not a credential.
- No personal or regulated information is submitted to the site.

## Feedback prompts
- Which explanation was confusing?
- Which simulation best helped you understand the concept, and why?
- Did any button, keyboard control, or mobile view fail?
- Could you apply what you learned in a job or daily task?
- What should be added or simplified?

## Privacy
No central learner analytics exist. If collecting pilot feedback, use a separately approved process and request only aggregate, non-identifying feedback. Local learning summaries are self-reported, not authenticated.
