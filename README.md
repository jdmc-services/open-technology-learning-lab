# Open Technology Learning Lab

A free, independent, globally accessible technology education pilot. The site is original educational material and is not sponsored or endorsed by an institution, vendor, or certification body.

## Preview locally

Open `index.html` in a browser, then choose **Computer Foundations**. All HTML, CSS, JavaScript and SVG files are included; no build system, account, CDN or backend is required. For the most consistent behavior, run `python -m http.server 8000` in this folder and visit `http://localhost:8000/`.

## First learning path

`learning-paths/computer-foundations/index.html` contains four interactive modules: (1) Information & Number Systems, (2) Networking, (3) Software & Applications, (4) Troubleshooting. Each includes original instruction, workplace application, browser-only simulation, scenario, and eight knowledge-check questions with rationales (32 total).

## Learner privacy and safety

No analytics, cookies, sign-in, external requests, accounts or server-side data collection. Quiz progress is stored in the learner's browser `localStorage`; learners can clear it from the progress page. Downloaded summaries are self-reported and not tamper-proof. Do not enter real passwords, regulated data, or confidential information. Simulations do not touch real networks or systems.

## GitHub Pages publication (only after approval)

1. Create a **new public repository** named `open-technology-learning-lab`. Do not modify the existing BrewByte repository.
2. Upload the **contents** of this package to the repository root, preserving folders. Do not upload the ZIP as a single file.
3. Under Settings → Pages, choose **Deploy from a branch**, `main`, `/(root)` and save.
4. Once deployment succeeds, visit `https://jdmc-services.github.io/open-technology-learning-lab/`.
5. Open all four modules, complete a simulation, submit a quiz, download progress, and test on mobile.

## Content stewardship

No proprietary slide images, third-party assessment items, or commercial brand/course content is included. The content is original and vendor-neutral. Creator attribution is intentionally discreet. Future tracks are clearly labeled as planned, not active.
